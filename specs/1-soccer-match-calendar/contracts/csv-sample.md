## フィールド詳細

### Group（グループ）

- **型**: 文字列
- **必須**: いいえ
- **説明**: 試合のグループ分類（例: EAST, WEST）
- **例**: `EAST`, `WEST`

### Round（ラウンド）

- **型**: 数値または文字列
- **必須**: いいえ
- **説明**: ラウンド番号
- **例**: `1`, `2`

### Date（日付）

- **型**: 日付文字列
- **必須**: はい
- **形式**: `YYYY-MM-DD`
- **説明**: 試合の日付
- **例**: `2026-02-06`

### Kickoff（キックオフ時間）

- **型**: 時間文字列 または "未定"
- **必須**: はい
- **形式**: `HH:MM`（24時間形式）または `未定`
- **説明**: キックオフ時間。未定の場合は「未定」と記載
- **例**: `19:00`, `13:30`, `13:05`, `未定`
- **制約**: 「未定」の場合は日時結合を行わず、日付のみを保持する

### Home（ホームチーム）

- **型**: 文字列
- **必須**: はい
- **説明**: ホームチーム名
- **例**: `横浜Ｆ・マリノス`, `ＦＣ東京`

### Away（アウェイチーム）

- **型**: 文字列
- **必須**: はい
- **説明**: アウェイチーム名
- **例**: `ＦＣ町田ゼルビア`, `鹿島アントラーズ`

### Stadium（スタジアム）

- **型**: 文字列 または "未定"
- **必須**: いいえ
- **説明**: スタジアム名。未定の場合は「未定」と記載
- **例**: `日産スタジアム`, `味の素スタジアム`, `未定`

### Broadcast（放送局）

- **型**: 文字列
- **必須**: いいえ
- **説明**: 放送局情報（複数の場合は `/` で区切る）
- **例**: `DAZN`, `DAZN/NHK BS`, `DAZN/日本テレビ系`

## 日時結合ルール

`Date`と`Kickoff`フィールドを結合して、ISO 8601形式の日時文字列を生成します：

- **タイムゾーン**: 日本標準時（JST, UTC+9）を想定
- **結合形式**: `{Date}T{Kickoff}:00+09:00`
- **例**: 
  - `2026-02-06` + `19:00` → `2026-02-06T19:00:00+09:00`
  - `2026-02-07` + `13:30` → `2026-02-07T13:30:00+09:00`
  - `2026-02-08` + `13:05` → `2026-02-08T13:05:00+09:00`
- **「未定」の処理**: `Kickoff`が「未定」の場合、日時結合は行わず、`dateTime`は`null`または空文字列として保存。UIでは日付と「未定」を表示する。

## 注意事項

1. **ヘッダー行**: 最初の行は必ずヘッダー行でなければなりません
2. **空行**: 最後の行が空行でも問題ありません（無視されます）
3. **特殊文字**: チーム名やスタジアム名に全角文字（Ｆ、・等）が含まれる場合があります
4. **引用符**: フィールドにカンマが含まれる場合は、ダブルクォートで囲む必要があります
5. **エンコーディング**: UTF-8で保存されていることを確認してください
6. **未定値**: KickoffとStadiumフィールドには「未定」という値が存在する可能性があります。これは有効な値として扱われます

## バリデーション例

### 正常なデータ行

```csv
EAST,1,2026-02-06,19:00,横浜Ｆ・マリノス,ＦＣ町田ゼルビア,日産スタジアム,DAZN
```

### 正常なデータ行（未定を含む）

```csv
EAST,1,2026-02-06,未定,横浜Ｆ・マリノス,ＦＣ町田ゼルビア,日産スタジアム,DAZN
```
→ Kickoffが「未定」（有効な値）

```csv
EAST,1,2026-02-06,19:00,横浜Ｆ・マリノス,ＦＣ町田ゼルビア,未定,DAZN
```
→ Stadiumが「未定」（有効な値）

### エラーとなるデータ行

```csv
EAST,1,2026-02-06,,横浜Ｆ・マリノス,ＦＣ町田ゼルビア,日産スタジアム,DAZN
```
→ Kickoffが空（必須フィールド欠落）

```csv
EAST,1,2026-13-45,19:00,横浜Ｆ・マリノス,ＦＣ町田ゼルビア,日産スタジアム,DAZN
```
→ Dateが無効な形式（存在しない日付）

```csv
EAST,1,2026-02-06,25:00,横浜Ｆ・マリノス,ＦＣ町田ゼルビア,日産スタジアム,DAZN
```
→ Kickoffが範囲外（24時間形式の範囲外）

```csv
EAST,1,2026-02-06,不明,横浜Ｆ・マリノス,ＦＣ町田ゼルビア,日産スタジアム,DAZN
```
→ Kickoffが「未定」でも有効な時間形式でもない
