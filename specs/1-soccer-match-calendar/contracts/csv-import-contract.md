# CSV Import Contract: CSVインポート仕様

**Feature**: サッカー試合予定カレンダーアプリケーション  
**Date**: 2026-01-09  
**Status**: Draft

## 概要

CSVファイルから試合予定をインポートする機能の仕様を定義します。

## CSVフォーマット

### 基本構造

```csv
Group,Round,Date,Kickoff,Home,Away,Stadium,Broadcast
EAST,1,2026-02-06,19:00,横浜Ｆ・マリノス,ＦＣ町田ゼルビア,日産スタジアム,DAZN
WEST,1,2026-02-06,19:00,京都サンガF.C.,ヴィッセル神戸,サンガスタジアム by KYOCERA,DAZN
EAST,1,2026-02-07,13:00,ジェフユナイテッド千葉,浦和レッズ,フクダ電子アリーナ,DAZN/NHK BS
```

### フィールド定義

| フィールド名 | 必須 | 型 | 説明 | 例 |
|------------|------|-----|------|-----|
| Group | オプション | 文字列 | グループ（EAST/WEST等） | `EAST` |
| Round | オプション | 数値または文字列 | ラウンド番号 | `1` |
| Date | 必須 | 日付文字列 (YYYY-MM-DD) | 試合の日付 | `2026-02-06` |
| Kickoff | 必須 | 時間文字列 (HH:MM) または "未定" | キックオフ時間 | `19:00`, `未定` |
| Home | 必須 | 文字列 | ホームチーム名 | `横浜Ｆ・マリノス` |
| Away | 必須 | 文字列 | アウェイチーム名 | `ＦＣ町田ゼルビア` |
| Stadium | オプション | 文字列 または "未定" | スタジアム名 | `日産スタジアム`, `未定` |
| Broadcast | オプション | 文字列 | 放送局情報 | `DAZN` |

### 日時結合ルール

`Date`と`Kickoff`フィールドを結合して、ISO 8601形式の日時文字列を生成します：
- タイムゾーンは日本標準時（JST, UTC+9）を想定
- 結合形式: `{Date}T{Kickoff}:00+09:00`
- 例: `2026-02-06` + `19:00` → `2026-02-06T19:00:00+09:00`
- **「未定」の処理**: `Kickoff`が「未定」の場合、`dateTime`は`null`または空文字列として保存し、日付のみ（`Date`）を保持する。UIでは「未定」と表示する。

### エンコーディング

- UTF-8（BOM付きまたはBOMなし）

### 区切り文字

- カンマ（`,`）

### 引用符

- フィールドにカンマや改行が含まれる場合は、ダブルクォート（`"`）で囲む

**例**:
```csv
日時,ホームチーム,アウェイチーム,会場,その他情報
2026-01-15T14:00:00+09:00,"チームA,東京",チームB,"スタジアムX,第1グラウンド",リーグ戦
```

## パーシング仕様

### CSVParserService

CSVファイルをパースしてMatchオブジェクトの配列に変換するサービス。

#### `parseCSV(file: File): Promise<ParseResult>`

CSVファイルをパースします。

**パラメータ**:
- `file`: パースするCSVファイル（ブラウザのFileオブジェクト）

**戻り値**: `ParseResult` オブジェクト
```typescript
interface ParseResult {
  matches: Match[];           // 正常にパースされた試合予定
  errors: ParseError[];        // パースエラーのリスト
  warnings: ParseWarning[];   // 警告のリスト
}
```

**エラー**: ファイルの読み込みに失敗した場合、エラーをスローします。

### バリデーションルール

#### 必須フィールドチェック

- Date、Kickoff、Home、Awayが存在し、空文字列でないこと

#### 日時形式チェック

- Dateが有効な日付形式（YYYY-MM-DD）であること
- Kickoffが有効な時間形式（HH:MM）または「未定」であること
- Kickoffが「未定」でない場合、DateとKickoffを結合した日時が有効な日時であること（存在しない日付でない）
- Kickoffが「未定」でない場合、時間が24時間形式の範囲内（00:00-23:59）であること

#### 特殊値の処理

- **Kickoff = "未定"**: 有効な値として扱い、日時結合は行わない。`dateTime`は`null`または空文字列として保存。
- **Stadium = "未定"**: 有効な値として扱い、そのまま保存する。

#### 文字列長チェック

- Home、Awayが空文字列でないこと
- 各フィールドが適切な長さであること（実装時に制限を定義）

#### データ変換ルール

CSVの各フィールドをMatchオブジェクトに変換する際のマッピング：

- `Date` + `Kickoff` → `dateTime` (ISO 8601形式に変換、Kickoffが「未定」の場合は`null`または空文字列)
- `Home` → `homeTeam`
- `Away` → `awayTeam`
- `Stadium` → `venue` (「未定」の場合はそのまま保存)
- `Group` + `Round` + `Broadcast` → `additionalInfo` (結合して保存、または個別フィールドとして保存)

### エラーハンドリング

#### ParseError

パースエラーを表すオブジェクト：

```typescript
interface ParseError {
  row: number;              // エラーが発生した行番号（1ベース）
  field?: string;          // エラーが発生したフィールド名
  message: string;          // エラーメッセージ（日本語）
  data?: string;           // 問題のあるデータ
}
```

#### ParseWarning

パース警告を表すオブジェクト：

```typescript
interface ParseWarning {
  row: number;              // 警告が発生した行番号（1ベース）
  field?: string;          // 警告が発生したフィールド名
  message: string;          // 警告メッセージ（日本語）
  data?: string;           // 問題のあるデータ
}
```

### エラーケース

1. **ファイル形式エラー**: CSVファイルでない、または読み込めない
2. **ヘッダー行エラー**: 必須のヘッダー（Date, Kickoff, Home, Away）が存在しない、または形式が不正
3. **必須フィールド欠落**: Date、Kickoff、Home、Awayが存在しない、または空
4. **日付形式エラー**: Dateが有効な日付形式（YYYY-MM-DD）でない
5. **時間形式エラー**: Kickoffが有効な時間形式（HH:MM）でも「未定」でもない
6. **日時妥当性エラー**: Kickoffが「未定」でない場合、DateとKickoffを結合した日時が存在しない日付である、または時間が範囲外
7. **文字列長エラー**: Home、Awayが空文字列である

### 警告ケース

1. **重複データ**: 同じ試合（日時、ホームチーム、アウェイチームが同一）が既に存在する
2. **オプションフィールド欠落**: オプションフィールドが存在しない（エラーではない）
3. **未定値**: KickoffまたはStadiumが「未定」の場合、警告として表示（エラーではない）

## インポート処理フロー

1. **ファイル選択**: ユーザーがCSVファイルを選択
2. **ファイル読み込み**: ファイルを読み込む
3. **CSVパーシング**: PapaParseを使用してCSVをパース
4. **データ変換**: パースされたデータをMatchオブジェクトに変換
5. **バリデーション**: 各Matchオブジェクトをバリデーション
6. **重複チェック**: 既存の試合予定と重複していないかチェック
7. **エラー集計**: エラーと警告を集計
8. **結果表示**: 
   - エラーがある場合: エラーメッセージを表示し、インポートを中止
   - 警告がある場合: 警告を表示し、ユーザーに確認を求める
   - 正常な場合: データを保存し、成功メッセージを表示

## ユーザーインターフェース

### インポート画面

- ファイル選択ボタン
- インポート実行ボタン
- 進捗表示（オプション）
- エラー/警告メッセージ表示エリア

### エラーメッセージ表示

エラーがある場合、以下の情報を表示：

- エラーが発生した行番号
- エラーの原因
- 問題のあるデータ（該当する場合）

### 警告メッセージ表示

警告がある場合、以下の情報を表示：

- 警告が発生した行番号
- 警告の内容
- 続行するかどうかの確認

## 実装時の考慮事項

### パフォーマンス

- 大きなCSVファイル（1000行以上）の場合、非同期処理でUIをブロックしない
- 進捗表示を実装してユーザーに処理状況を伝える

### ユーザビリティ

- エラーメッセージは分かりやすく、日本語で表示する
- エラーが発生した行を特定しやすくする
- 部分的なインポート（エラー行をスキップ）のオプションを検討

### 拡張性

- CSVフォーマットの変更に対応できる柔軟な設計
- カスタムフィールドマッピングのサポート（将来の拡張）
