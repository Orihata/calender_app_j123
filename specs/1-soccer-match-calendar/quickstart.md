# Quickstart Guide: サッカー試合予定カレンダーアプリケーション

**Feature**: サッカー試合予定カレンダーアプリケーション  
**Date**: 2026-01-09  
**Status**: Draft

## 前提条件

- Node.js 18以上がインストールされていること
- npm または yarn がインストールされていること
- モダンブラウザ（Chrome, Firefox, Safari, Edgeの最新版）が利用可能であること

## セットアップ手順

### 1. 依存関係のインストール

```bash
npm install
```

または

```bash
yarn install
```

### 2. 開発サーバーの起動

```bash
npm run dev
```

または

```bash
yarn dev
```

アプリケーションは `http://localhost:5173` (Viteのデフォルトポート) で起動します。

### 3. ブラウザでアクセス

ブラウザで `http://localhost:5173` を開きます。

## 基本的な使用方法

### CSVファイルのインポート

1. アプリケーションのトップページで「CSVインポート」ボタンをクリック
2. CSVファイルを選択（ファイル形式の詳細は後述）
3. インポートが完了すると、カレンダーに試合予定が表示される

**CSVファイル形式**:
```csv
Group,Round,Date,Kickoff,Home,Away,Stadium,Broadcast
EAST,1,2026-02-06,19:00,横浜Ｆ・マリノス,ＦＣ町田ゼルビア,日産スタジアム,DAZN
WEST,1,2026-02-06,19:00,京都サンガF.C.,ヴィッセル神戸,サンガスタジアム by KYOCERA,DAZN
```

詳細は `contracts/csv-sample.md` を参照してください。

### カレンダーで試合予定を確認

1. カレンダー上で日付をクリック
2. その日付のすべての試合予定が一覧表示される
3. 複数の試合がある場合は、すべてが表示される

### 観戦予定の設定

1. カレンダーまたは試合一覧から試合を選択
2. 「観戦予定に追加」ボタンをクリック
3. 観戦予定一覧ページで確認できる

### 観戦予定の一覧表示

1. ナビゲーションメニューから「観戦予定」を選択
2. 観戦予定としてマークしたすべての試合が表示される

### 観戦予定の削除

1. 観戦予定一覧から削除したい試合を選択
2. 「観戦予定から削除」ボタンをクリック

### 観戦予定の一覧出力

1. 観戦予定一覧ページで「一覧出力」ボタンをクリック
2. 選択した形式（JSON、CSV等）で出力される

## テストシナリオ

### シナリオ1: CSVインポートとカレンダー表示

**前提条件**: アプリケーションが起動している

**手順**:
1. CSVファイルをインポート
2. カレンダーで試合予定が表示されることを確認
3. 特定の日付をクリックして、その日の試合予定が表示されることを確認

**期待結果**: 
- CSVファイルが正常にインポートされる
- カレンダーに試合予定が表示される
- 日付をクリックすると、その日の試合予定が一覧表示される

### シナリオ2: 観戦予定の設定と管理

**前提条件**: 試合予定がインポートされている

**手順**:
1. 試合を選択して観戦予定としてマーク
2. 観戦予定一覧ページで確認
3. 観戦予定のマークを解除
4. 観戦予定一覧から削除されることを確認

**期待結果**:
- 試合が観戦予定としてマークされる
- 観戦予定一覧に表示される
- マークを解除すると、観戦予定一覧から削除される

### シナリオ3: エラーハンドリング

**前提条件**: アプリケーションが起動している

**手順**:
1. 無効なCSVファイル（形式が不正、必須フィールドが欠落等）をインポート
2. エラーメッセージが表示されることを確認
3. データが読み込まれていないことを確認

**期待結果**:
- 適切なエラーメッセージが表示される
- データが読み込まれない
- 既存のデータに影響がない

### シナリオ4: モバイル表示

**前提条件**: アプリケーションが起動している

**手順**:
1. ブラウザの開発者ツールでモバイルビュー（320px幅）に切り替え
2. カレンダーが適切に表示されることを確認
3. 試合予定が読みやすく表示されることを確認

**期待結果**:
- モバイル画面でも適切に表示される
- スクロールなしで主要情報が確認できる
- タッチ操作が可能である

## トラブルシューティング

### 問題: CSVファイルがインポートできない

**原因と対処**:
- CSVファイルの形式が正しくない可能性があります。形式を確認してください。
- ファイルのエンコーディングがUTF-8であることを確認してください。
- ブラウザのコンソールでエラーメッセージを確認してください。

### 問題: データが保存されない

**原因と対処**:
- ブラウザのlocalStorageが無効になっていないか確認してください。
- ブラウザのプライベートモードを使用している場合、localStorageが制限される可能性があります。
- ブラウザのストレージ容量が不足している可能性があります。

### 問題: カレンダーが表示されない

**原因と対処**:
- ブラウザのコンソールでエラーメッセージを確認してください。
- ページをリロードしてください。
- ブラウザのキャッシュをクリアしてください。

## データのバックアップと復元

### バックアップ

localStorageのデータはブラウザの開発者ツールから確認・エクスポートできます：

1. ブラウザの開発者ツールを開く（F12）
2. Applicationタブ（Chrome）またはStorageタブ（Firefox）を選択
3. Local Storage を展開
4. データをコピーしてJSONファイルとして保存

### 復元

1. バックアップしたJSONファイルを読み込む
2. アプリケーションの設定画面から「データ復元」を選択
3. JSONファイルを選択してインポート
