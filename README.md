# サッカー試合予定カレンダーアプリケーション

サッカークラブの試合予定を管理するPWA（Progressive Web App）対応のローカルブラウザアプリケーションです。

## 機能

- **マスタデータの自動読み込み**: アプリ起動時に試合予定データを自動的に読み込み
- **CSVファイルから試合予定をインポート**: PC環境での手動インポートも可能
- **カレンダー形式で試合予定を表示**: 日付別に試合予定を一覧表示
- **観戦予定の設定と管理**: 現地観戦予定と放送視聴予定を分けて管理
- **観戦予定の一覧出力**: 選択した試合のみを一覧として出力
- **PWA対応**: モバイルデバイスにインストール可能、オフライン動作対応

## 技術スタック

- React 18+
- React Router
- Vite
- PapaParse (CSVパーシング)
- date-fns (日付操作)
- localStorage (データ永続化)

## セットアップ

### 依存関係のインストール

```bash
npm install
```

### マスタデータの生成

CSVファイルからマスタデータ（JSON）を生成します：

```bash
npm run generate-master-data
```

これにより `public/data/master-matches.json` が生成されます。

### 開発サーバーの起動

```bash
npm run dev
```

アプリケーションは `http://localhost:5173` で起動します。

### ビルド

```bash
npm run build
```

ビルドされたファイルは `dist/` ディレクトリに出力されます。

### PWAとしてのデプロイ

ビルド後、`dist/` ディレクトリを静的ホスティングサービス（Netlify、Vercel、GitHub Pages等）にデプロイできます。

**注意**: PWAとして動作させるには、HTTPS環境が必要です（localhostは除く）。

## PWA機能

### インストール方法

1. モバイルブラウザでアプリにアクセス
2. ブラウザのメニューから「ホーム画面に追加」を選択
3. アプリがインストールされ、アプリアイコンから起動可能になります

### オフライン動作

- Service Workerにより、一度アクセスしたアプリはオフラインでも動作します
- マスタデータ（試合予定）はアプリにバンドルされているため、初回からオフラインで利用可能です
- ユーザーデータ（観戦予定）はlocalStorageに保存されるため、オフラインでも管理可能です

### データ管理

- **マスタデータ（試合予定）**: `public/data/master-matches.json` にバンドル
  - アプリ起動時に自動的に読み込まれます
  - 既存データがある場合はスキップされます（手動インポートを優先）
- **ユーザーデータ（観戦予定）**: localStorageで管理
  - デバイス固有のデータとして保存されます
