# Version 2.0.1 開発タスク — シーズンアーカイブ

**ブランチ**: `dev_v2.0`  
**対象バージョン**: 2.0.1

## 背景

- v2.0.0 でマスタデータを **2026/2027シーズン**（2026年8月〜2027年6月）に更新
- v1.x 利用者の端末には **2026特別シーズン**（2026年2月〜6月）の試合・観戦予定が localStorage に残存している
- 既存データがある場合、マスタ自動読込がスキップされるため、前シーズン情報が表示され続ける

## 開発目的

1. 2026特別シーズンのユーザーデータ（試合・観戦予定）を退避する
2. 2026/2027シーズン利用時に、表示・カレンダー出力から前シーズン情報を除外する
3. 設定画面からユーザーが明示的に「アーカイブ」できる（非可逆）
4. 退避データの将来活用は検討対象とし、**現時点ではアプリUIからの読取りは行わない**

## シーズン定義

| シーズン | 期間 | ID |
|----------|------|-----|
| 2026特別シーズン | 2026-02-01 〜 2026-06-30 | `special-2026` |
| 2026/2027シーズン | 2026-08-01 〜 2027-06-30 | `j2026-27` |

## アーカイブ処理フロー

```
設定 > アーカイブ実行
  → 2026-02〜06 の試合・観戦予定を archivedSeasons に退避
  → アクティブな matches / attendancePlans から削除
  → 現行マスタの未登録試合を取り込み
  → ページリロードを促す
```

## データ構造（localStorage: `archivedSeasons`）

```json
[
  {
    "id": "special-2026",
    "label": "2026特別シーズン",
    "period": { "startDate": "2026-02-01", "endDate": "2026-06-30" },
    "archivedAt": "ISO8601",
    "matchCount": 0,
    "attendancePlanCount": 0,
    "matches": [],
    "attendancePlans": []
  }
]
```
