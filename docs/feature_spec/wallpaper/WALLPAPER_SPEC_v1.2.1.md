# 待受画面画像出力機能 - 仕様書

**機能**: T065 - 画像出力機能の実装（待受画面用）  
**バージョン**: 1.2.1  
**作成日**: 2026-01-09  
**更新日**: 2026-01-XX（最終更新）  
**ステータス**: ✅ 実装完了

**参照**: 高レベル設計・全体構造については `specs/1-soccer-match-calendar/spec.md` のUser Story 4を参照してください。本ファイルは実装詳細仕様（SSOT）です。

**重要**: 
- カード内レイアウトの仕様は、**`docs/feature_spec/wallpaper/card_layout_sample.json`をSSOT（Single Source of Truth）**とします。
- スティック内レイアウトの仕様は、**`docs/feature_spec/wallpaper/stick_layout_sample.json`をSSOT（Single Source of Truth）**とします。
これらのJSONファイルに記載されている座標、フォントサイズ、フォントウェイトを基準として実装してください。

## 概要

ユーザーが選択した試合データを、携帯電話の待受画面用の画像として出力する機能を実装します。  
**選択した全試合を1枚の画像にまとめて出力**します。  
**カードレイアウト**と**スティックレイアウト**の2種類のレイアウトタイプから選択可能です。

## ✅ 確定仕様

### 1. 画像仕様

#### 1.1 サイズ・解像度
- **確定**: 1080x2400px（縦長、9:20）固定
- 複数サイズ対応は将来拡張として検討

#### 1.2 ファイルフォーマット
- **確定**: PNG形式（高画質、透過対応）

#### 1.3 色空間
- **確定**: sRGB（標準）

---

### 2. 出力対象・範囲

#### 2.1 出力方式
- **確定**: **選択した全試合を1画像にまとめる**
- **レイアウトタイプ**: カードレイアウトまたはスティックレイアウトを選択可能

#### 2.2 最大表示試合数
- **カードレイアウト**: 最大39試合（3列×13行）
- **スティックレイアウト**: 最大39試合（1列×39行）

#### 2.3 フィルタリング
- **確定**: **現地観戦のみ**で実装（初回実装）
- カテゴリフィルター: `venue`（現地観戦予定）のみ対象
- 将来拡張: 放送視聴予定も対応

---

### 3. レイアウト・デザイン仕様

#### 3.1 基本レイアウト構造

**カードレイアウト**:
- **確定**: **カード型**
- 情報をカード形式で配置
- カード内のレイアウトは`docs/feature_spec/wallpaper/card_layout_sample.json`をSSOTとする
- **配置**: 3列×n行（縦方向優先）

**スティックレイアウト**:
- **確定**: **スティック型**
- 情報をスティック形式で配置（カードレイアウトより簡易的）
- スティック内のレイアウトは`docs/feature_spec/wallpaper/stick_layout_sample.json`をSSOTとする
- **配置**: 1列×n行（縦方向、最大39行）
- 1試合ごとに1本のスティックという関係性
- **メモエリア**: 高さ2px、メモ内容は非表示（背景のみ表示）
- **下部余白**: 100px

#### 3.2 表示情報

**カードレイアウト内に表示される情報**:
1. **グループ**: EAST/WEST等
2. **ラウンド**: 第X節
3. **日付**: `M/d`形式（例: `12/16`）
4. **曜日**: 漢字1文字（例: `金`）
5. **KO時間**: `HH:MM`形式または「未定」
6. **会場名**: スタジアム名
7. **ホームチーム**: チーム名（右側上部）
8. **アウェイチーム**: チーム名（右側下部）

**スティックレイアウト内に表示される情報**:
1. **日付**: `M/d`形式（例: `12/16`）
2. **曜日**: 漢字1文字（例: `金`）
3. **ホームチーム**: チーム名
4. **アウェイチーム**: チーム名
5. **KO時間**: `HH:MM`形式または「未定」
6. **会場名**: スタジアム名
7. **グループ**: EAST/WEST等
8. **ラウンド**: 第X節

#### 3.3 デザイン要素

**カード/スティック背景**:
- **グラデーション**: 右から左へのグラデーション
  - 右端: `#F0F7FC`（より明るく、彩度を下げた淡い青）
  - 左端: `#E8F2F8`（より明るく、彩度を下げたより淡い青）
- **カテゴリ**: 現地観戦（venue）のみ対応

**文字色**:
- **ホームチーム**: 色マスタ（`color-master.json`）の`text`カラーを使用
- **アウェイチーム**: 色マスタ（`color-master.json`）の`text`カラーを使用
- **その他のテキスト**: デフォルトの`textColor`（`#1565C0`）を使用
- **フォント**: Noto Serif JP

**カード/スティックの枠**:
- 枠線なし（影のみ）

**カード/スティックの影**:
- `rgba(0,0,0,0.15)`
- ぼかし: 8px
- オフセット: (0, 2)

### 4. 色マスタ機能

#### 4.1 色マスタファイル
- **ファイルパス**: `public/data/color-master.json`
- **形式**: JSON
- **構造**:
```json
{
  "version": "1.2.0",
  "lastUpdated": "2026-01-13T15:27:03+09:00",
  "colors": {
    "チーム名": {
      "original": "#カラーコード",
      "background1": "#カラーコード",
      "background2": "#カラーコード",
      "text": "#カラーコード",
      "gradientStart": "#カラーコード",
      "gradientEnd": "#カラーコード"
    }
  }
}
```

#### 4.2 色の種類
- **original**: 元のチームカラーコード
- **background1**: 背景色用バリエーション1（明度0.85、彩度50%）
- **background2**: 背景色用バリエーション2（明度0.90、彩度35%）
- **text**: 文字用の色（濃く、読みやすく）
- **gradientStart**: グラデーション開始色（淡い色）
- **gradientEnd**: グラデーション終了色（より淡い色）

#### 4.3 色マスタの適用範囲
- **観戦予定一覧ページ**: HomeとAwayの文字色に`text`カラーを適用
- **カレンダーページ**: HomeとAwayの文字色に`text`カラーを適用
- **待受画面画像生成**: HomeとAwayの文字色に`text`カラーを適用（カードレイアウト・スティックレイアウト共通）

#### 4.4 デフォルト色
- 色マスタに存在しないチーム名の場合、デフォルト色（`#2c3e50`）を使用

### 5. UI/UX仕様

#### 5.1 画像生成方法
- **生成トリガー**: ボタンクリック（「画像を生成」ボタン）
- **生成場所**: 観戦予定一覧ページ

#### 5.2 プレビュー機能
- **確定**: 生成後プレビュー（生成した画像をモーダルで表示）
- プレビュー後にダウンロードボタンを表示

#### 5.3 ダウンロード方法
- **確定**: 1枚の画像として出力（全試合をまとめる）
- **ファイル名**: `wallpaper_001.png`（固定）

#### 5.4 背景色の選択
- **UI**: ごくごく淡い7色から選択可能（モーダル形式）
  - 選択中の色を1色表示するボタンをクリックすると、色選択モーダルが開く
  - モーダル内に7色をグリッド（4列）で配置
- **選択可能な色**:
  1. 白（`#FFFFFF`）
  2. 淡い青（`#F0F7FC`）
  3. 淡いピンク（`#FFF0F5`）
  4. 淡いグリーン（`#F0FFF0`）
  5. 淡いイエロー（`#FFFFF0`）
  6. 淡いパープル（`#F5F0FF`）
  7. 淡いグレー（`#F5F5F5`）
- **デフォルト**: `#FFFFFF`（白）

#### 5.5 レイアウトタイプの選択
- **UI**: プルダウンでレイアウトタイプを選択可能
- **デフォルト**: 「カード」
- **オプション**:
  1. **カード**（`card`）:
     - 3列×n行の配置
     - 最大39試合まで表示
  2. **スティック**（`stick`）:
     - 1列×n行の配置
     - 最大39試合まで表示
     - カードレイアウトより簡易的な表示

#### 5.6 カラーリングの選択
- **UI**: プルダウンでカラーリングを選択可能
- **デフォルト**: 「通常」パターン
- **パターン一覧**:
  1. **通常パターン**（`current`）:
     - 太字: 応援しているクラブ（plan.supportingTeamに基づく）
     - メモ欄の背景色: 応援しているクラブの文字色
     - メモ欄の文字色: 白（#FFFFFF）
  2. **クラシックパターン**（`classic`）:
     - 太字: ホームのクラブ（常にhome）
     - メモ欄の背景色: デフォルト色（紺色: #2A456F）
     - メモ欄の文字色: 白（#FFFFFF）
  3. **ホームゲームパターン**（`home-based`）:
     - 太字: ホームのクラブ（常にhome）
     - メモ欄の背景色: ホームのクラブの文字色
     - メモ欄の文字色: 白（#FFFFFF）

#### 5.7 エラーハンドリング

**観戦予定がない場合**:
- エラーメッセージ: 「現地観戦予定がありません。」

**生成失敗時**:
- エラーメッセージ: 「画像の生成に失敗しました: [エラー詳細]」

**試合数超過の場合**:
- **カードレイアウト**: 39試合を超える場合、警告メッセージを表示
  - 「39試合を超える観戦予定があります（全X試合）。最初の39試合のみ表示します。」
- **スティックレイアウト**: 39試合を超える場合、警告メッセージを表示
  - 「39試合を超える観戦予定があります（全X試合）。最初の39試合のみ表示します。」

### 6. 技術仕様

#### 6.1 使用技術
- **Canvas API**: 画像生成（ネイティブCanvas API）
- **フォント**: Noto Serif JP（Webフォント）

#### 6.2 カード配置アルゴリズム

**縦方向優先（列優先）**:
```javascript
const col = Math.floor(index / ROWS)  // 列: 0, 0, 0, ..., 1, 1, 1, ...
const row = index % ROWS              // 行: 0, 1, 2, ..., 0, 1, 2, ...
```

**配置例（45枚の場合）**:
```
1  16  31
2  17  32
3  18  33
...
15 30  45
```

#### 6.3 スティック配置アルゴリズム

**縦方向（1列）**:
- 上から順に配置（または下端固定から逆算）
- スティック間のマージン: 8px
- 最大50個まで表示

#### 6.4 色マスタの読み込み
- **読み込みタイミング**: 画像生成時、観戦予定一覧表示時、カレンダー表示時
- **キャッシュ**: 一度読み込んだ色マスタはメモリにキャッシュ
