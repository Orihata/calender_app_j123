# 待受画面画像出力機能 - 仕様書

**機能**: T065 - 画像出力機能の実装（待受画面用）  
**バージョン**: 1.2.0  
**作成日**: 2026-01-09  
**更新日**: 2026-01-13  
**ステータス**: ✅ 実装完了

**参照**: 高レベル設計・全体構造については `specs/1-soccer-match-calendar/spec.md` のUser Story 4を参照してください。本ファイルは実装詳細仕様（SSOT）です。

**重要**: カード内レイアウトの仕様は、**`docs/feature_spec/wallpaper/card_layout_sample.json`をSSOT（Single Source of Truth）**とします。  
このJSONファイルに記載されている座標、フォントサイズ、フォントウェイトを基準として実装してください。

## 概要

ユーザーが選択した試合データを、携帯電話の待受画面用の画像として出力する機能を実装します。  
**選択した全試合を1枚の画像にまとめて出力**します。

---

## ✅ 確定仕様

### 1. 画像仕様

#### 1.1 サイズ・解像度
- **確定**: 1080x2400px（縦長、9:20）固定
- 複数サイズ対応は将来拡張として検討

#### 1.2 ファイルフォーマット
- **確定**: PNG形式（高画質、透過対応）

#### 1.3 色空間
- **確定**: sRGB（標準）

---

### 2. 出力対象・範囲

#### 2.1 出力方式
- **確定**: **選択した全試合を1画像にまとめる**
- **最大表示試合数**: 51試合
- **カード配置**: **3列×15行（縦方向優先）**
  - 1列目: 0-14（15枚）
  - 2列目: 15-29（15枚）
  - 3列目: 30-44（15枚）
  - 4列目: 45-50（6枚、51枚の場合）

#### 2.2 フィルタリング
- **確定**: **現地観戦のみ**で実装（初回実装）
- カテゴリフィルター: `venue`（現地観戦予定）のみ対象
- 将来拡張: 放送視聴予定も対応

---

### 3. レイアウト・デザイン仕様

#### 3.1 基本レイアウト構造
- **確定**: **カード型**
- 情報をカード形式で配置
- カード内のレイアウトは`docs/feature_spec/wallpaper/card_layout_sample.json`をSSOTとする

#### 3.2 表示情報

**カード内に表示される情報**:
1. **グループ**: EAST/WEST等
2. **ラウンド**: 第X節
3. **日付**: `M/d`形式（例: `12/16`）
4. **曜日**: 漢字1文字（例: `金`）
5. **KO時間**: `HH:MM`形式または「未定」
6. **会場名**: スタジアム名
7. **ホームチーム**: チーム名（右側上部）
8. **アウェイチーム**: チーム名（右側下部）

#### 3.3 デザイン要素

**カード背景**:
- **グラデーション**: 右から左へのグラデーション
  - 右端: `#F0F7FC`（より明るく、彩度を下げた淡い青）
  - 左端: `#E8F2F8`（より明るく、彩度を下げたより淡い青）
- **カテゴリ**: 現地観戦（venue）のみ対応

**文字色**:
- **ホームチーム**: 色マスタ（`color-master.json`）の`text`カラーを使用
- **アウェイチーム**: 色マスタ（`color-master.json`）の`text`カラーを使用
- **その他のテキスト**: デフォルトの`textColor`（`#1565C0`）を使用
- **フォント**: Noto Sans JP

**カードの枠**:
- 枠線なし（影のみ）

**カードの影**:
- `rgba(0,0,0,0.15)`
- ぼかし: 8px
- オフセット: (0, 2)

---

### 4. 色マスタ機能

#### 4.1 色マスタファイル
- **ファイルパス**: `public/data/color-master.json`
- **形式**: JSON
- **構造**:
```json
{
  "version": "1.2.0",
  "lastUpdated": "2026-01-13T15:27:03+09:00",
  "colors": {
    "チーム名": {
      "original": "#カラーコード",
      "background1": "#カラーコード",
      "background2": "#カラーコード",
      "text": "#カラーコード",
      "gradientStart": "#カラーコード",
      "gradientEnd": "#カラーコード"
    }
  }
}
```

#### 4.2 色の種類
- **original**: 元のチームカラーコード
- **background1**: 背景色用バリエーション1（明度0.85、彩度50%）
- **background2**: 背景色用バリエーション2（明度0.90、彩度35%）
- **text**: 文字用の色（濃く、読みやすく）
- **gradientStart**: グラデーション開始色（淡い色）
- **gradientEnd**: グラデーション終了色（より淡い色）

#### 4.3 色マスタの適用範囲
- **観戦予定一覧ページ**: HomeとAwayの文字色に`text`カラーを適用
- **カレンダーページ**: HomeとAwayの文字色に`text`カラーを適用
- **待受画面画像生成**: HomeとAwayの文字色に`text`カラーを適用

#### 4.4 デフォルト色
- 色マスタに存在しないチーム名の場合、デフォルト色（`#2c3e50`）を使用

### 5. UI/UX仕様

#### 5.1 画像生成方法
- **生成トリガー**: ボタンクリック（「画像を生成」ボタン）
- **生成場所**: 観戦予定一覧ページ

#### 5.2 プレビュー機能
- **確定**: 生成後プレビュー（生成した画像をモーダルで表示）
- プレビュー後にダウンロードボタンを表示

#### 5.3 ダウンロード方法
- **確定**: 1枚の画像として出力（全試合をまとめる）
- **ファイル名**: `wallpaper_001.png`（固定）

#### 5.4 背景色の選択
- **UI**: カラーピッカーで背景色を選択可能
- **デフォルト**: `#FFFFFF`（白）

#### 5.5 エラーハンドリング

**観戦予定がない場合**:
- エラーメッセージ: 「現地観戦予定がありません。」

**生成失敗時**:
- エラーメッセージ: 「画像の生成に失敗しました: [エラー詳細]」

**51試合超の場合**:
- 警告メッセージを画像下部に表示
- 「51試合を超える観戦予定があります。最初の51試合のみ表示します。」

---

### 6. 技術仕様

#### 6.1 使用技術
- **Canvas API**: 画像生成（ネイティブCanvas API）
- **フォント**: Noto Sans JP（Webフォント）

#### 6.2 カード配置アルゴリズム

**縦方向優先（列優先）**:
```javascript
const col = Math.floor(index / ROWS)  // 列: 0, 0, 0, ..., 1, 1, 1, ...
const row = index % ROWS              // 行: 0, 1, 2, ..., 0, 1, 2, ...
```

**配置例（45枚の場合）**:
```
1  16  31
2  17  32
3  18  33
...
15 30  45
```

#### 6.3 色マスタの読み込み
- **読み込みタイミング**: 画像生成時、観戦予定一覧表示時、カレンダー表示時
- **キャッシュ**: 一度読み込んだ色マスタはメモリにキャッシュ
