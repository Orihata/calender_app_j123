## 概要

本アプリケーションのUIデザインシステムをニューモーフィズム（Neumorphism）デザインに全面刷新しました。柔らかく立体的な見た目により、視覚的な深みとモダンな印象を実現しています。

## デザイン原則

### 基本方針

1. **浮き出し効果（Outset）**: カードやボタンなど、ユーザーが操作する要素は浮き上がるように表示
2. **沈み込み効果（Inset）**: コンテナや入力欄など、要素をまとめる領域は沈み込むように表示
3. **背景色の統一**: 全体的に`#f0f0f0`（明るいグレー）の背景色に統一
4. **丸みの強調**: すべての要素に適度な丸みを付与し、柔らかい印象を実現

### 影の設定

#### 浮き出し効果（Outset）
```css
box-shadow: 6px 6px 12px rgba(0, 0, 0, 0.2), 
            -6px -6px 12px rgba(255, 255, 255, 0.7);
```

#### 沈み込み効果（Inset）
```css
box-shadow: inset 6px 6px 12px rgba(0, 0, 0, 0.2), 
            inset -6px -6px 12px rgba(255, 255, 255, 0.7);
```

## コンポーネント別仕様

### ヘッダー

- **背景色**: `#f0f0f0`（ページ背景と同じ）
- **影**: 浮き出し効果（軽め）
- **テキスト色**: `#2c3e50`（濃いグレー）
- **高さ**: 固定（約60px）
- **位置**: 画面上部に固定

### フッターナビゲーション

- **背景色**: `#f0f0f0`
- **影**: 上部に浮き出し効果
- **位置**: 画面下部に固定
- **高さ**: 約80px（モバイル: 約70px）
- **アイコン**: 4つのナビゲーションアイコン
  - 📅 カレンダー
  - ✏️ データ編集
  - 📋 観戦予定
  - ⚙️ 設定
- **選択状態**: 淡い青色（`#b3d9ff`）の背景と沈み込み効果

### カード

#### 試合カード
- **背景色**: `#f0f0f0`
- **影**: 浮き出し効果
- **border-radius**: `20px`
- **アクセント**:
  - 現地観戦予定がある場合: 淡い青色の影（`rgba(0, 123, 255, 0.3)`）
  - 放送視聴予定がある場合: 淡い緑色の影（`rgba(40, 167, 69, 0.3)`）

#### 観戦予定カード
- **背景色**: `#f0f0f0`
- **影**: 浮き出し効果
- **border-radius**: `20px`
- **アクセント**: カテゴリに応じたアクセントカラーの影

### コンテナ

#### カレンダーグリッド
- **背景色**: `#f0f0f0`
- **影**: 沈み込み効果
- **border-radius**: `20px`
- **パディング**: `1rem`

#### その他のコンテナ
- **背景色**: `#f0f0f0`
- **影**: 沈み込み効果
- **border-radius**: `20px`
- **対象**: 
  - `.calendar-header`
  - `.selected-date-matches`
  - `.attendance-items`
  - `.data-edit-top`
  - `.import-csv-form`
  - `.storage-info`
  - `.data-management`
  - `.usage-info`

### ボタン

#### 通常ボタン（青・緑）
- **背景色**: 
  - 青: `#b3d9ff`（淡い青）
  - 緑: `#b3ffb3`（淡い緑）
- **テキスト色**: `#2c3e50`（濃いグレー）
- **影**: 浮き出し効果
- **border-radius**: `12px`

#### 危険ボタン（赤）
- **背景色**: `#dc3545`（濃い赤）
- **テキスト色**: `white`
- **影**: 浮き出し効果（強調）
- **border-radius**: `12px`
- **用途**: 削除、データクリアなど危険な操作

#### 選択中のボタン
- **背景色**: アクセントカラー（淡い青または淡い緑）
- **テキスト色**: `#2c3e50`
- **影**: 沈み込み効果
- **border-radius**: `12px`

### 入力欄

- **背景色**: `#f0f0f0`
- **影**: 沈み込み効果
- **border-radius**: `12px`
- **対象**: 
  - テキスト入力欄
  - テキストエリア
  - セレクトボックス

### モーダル

- **背景色**: `#f0f0f0`
- **影**: 浮き出し効果（強め）
- **border-radius**: `20px`
- **位置**: 画面中央
- **フッター考慮**: フッターナビゲーションの高さを考慮した位置調整
  - デスクトップ: `bottom: 80px`
  - モバイル: `bottom: 70px`

### カレンダー表示

#### カレンダー日付セル
- **通常**: 背景色なし、浮き出し効果なし
- **観戦予定がある日**: 
  - 背景色: `#fff9c4`（薄い黄色）
  - 影: 浮き出し効果（強調）
- **今日**: 
  - 背景色: `#fff59d`（やや濃い黄色）
  - 影: 浮き出し効果（強調）
- **選択された日**: 
  - 背景色: `#007bff`（青）
  - 影: 浮き出し効果

#### カレンダーグリッド
- **背景色**: `#f0f0f0`
- **影**: 沈み込み効果
- **border-radius**: `20px`
