# シーズンアーカイブ機能 仕様書 v2.0.1

**Version**: 2.0.1  
**Status**: Implemented  
**Date**: 2026-07-01

## 概要

2026特別シーズン（2026年2月〜6月）で蓄積したユーザーデータを、2026/2027シーズン（2026年8月〜）への移行時に退避する機能。

## 要件

### FR-1: シーズン境界

- 2026特別シーズン: `2026-02-01` 〜 `2026-06-30`（境界日を含む）
- 2026/2027シーズン: `2026-08-01` 〜 `2027-06-30`（境界日を含む）

### FR-2: アーカイブ対象

試合日が2026特別シーズンに属する以下を退避する。

- `matches`（試合予定）
- `attendancePlans`（観戦予定。対象試合に紐づくもの）

### FR-3: アーカイブ操作

- 設定画面に「2026特別シーズンをアーカイブ」ボタンを配置
- 実行前に確認ダイアログを表示
- **非可逆**（アプリUIからの復元不可）
- 同一シーズンの二重アーカイブを拒否

### FR-4: アーカイブ後の表示

アクティブデータから削除するため、以下に前シーズン情報は表示されない。

- カレンダー
- 観戦予定一覧
- 壁紙（カレンダー）画像出力
- JSON/CSVエクスポート

### FR-5: マスタデータ取込

アーカイブ完了後、現行 `master-matches.json` のうち未登録試合を自動取り込みする（日付+ホーム+アウェイで重複判定）。

### FR-6: 退避データの閲覧

現時点では **アプリUIからの読取り・復元は行わない**。`localStorage` の `archivedSeasons` に JSON として保持するのみ。

## ストレージ

| キー | 説明 |
|------|------|
| `matches` | アクティブな試合予定 |
| `attendancePlans` | アクティブな観戦予定 |
| `archivedSeasons` | アーカイブ済みシーズンデータの配列 |
