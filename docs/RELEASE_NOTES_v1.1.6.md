# リリースノート Version 1.1.6

**リリース日**: 2026-01-17

## 概要

1.1.5で実装した応援クラブの設定を、待ち受け画面画像生成の際に使用するようになりました。応援クラブが太字で表示され、メモ欄の背景色が応援クラブの色に変更されます。

## 主な変更内容

### 待ち受け画面画像生成への応援クラブ反映

- **応援クラブの太字表示**: 待ち受け画面画像生成時に、応援クラブが選択されているクラブ名を太字で表示
  - 応援クラブが選択されている場合: フォントウェイト700（太字）
  - 応援クラブが選択されていない場合: フォントウェイト400（通常）
  - 以前はhomeが常に太字でしたが、応援クラブに応じて動的に変更されます

- **メモ欄の背景色変更**: メモ欄の背景色を応援クラブの色に変更
  - 応援クラブが選択されている場合: そのチームのtextカラーを背景色に使用
  - 応援クラブが選択されていない場合: デフォルト色（紺色: `#2A456F`）を使用
  - チームカラーが取得できない場合もデフォルト色を使用

- **登録がないクラブの文字色**: 色マスタに登録がないクラブの文字色をメモ欄の背景色と同じ色に統一
  - 登録がないクラブの文字色: デフォルト色（紺色: `#2A456F`）
  - 以前はカテゴリ別のデフォルト色（現地観戦: 青系、放送視聴: 緑系）が使用されていました

### UIの改善

- **視覚的な一貫性**: 応援クラブが選択されているカードで、クラブ名とメモ欄が同じ色で統一され、より視覚的に分かりやすくなりました
- **デザインの統一**: 登録がないクラブも、メモ欄の背景色と統一された色で表示されるため、全体的なデザインが統一されました

### 技術的改善

- `src/services/imageExportService.js`:
  - `drawCard`関数: 応援クラブに応じてフォントウェイトを動的に設定
  - `drawMemoArea`関数: 応援クラブに応じてメモ欄の背景色を設定
  - 登録がないクラブの文字色をメモ欄の背景色と同じ色に統一

## 互換性

- 既存の観戦予定データ: そのまま動作します（応援クラブが未設定の場合はデフォルト色を使用）
- 既存機能への影響: なし
