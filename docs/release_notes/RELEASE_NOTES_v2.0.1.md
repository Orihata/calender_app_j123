# リリースノート Version 2.0.1

**リリース日**: 2026-07-01

## 概要

2026特別シーズン（2026年2月〜6月）から2026/2027シーズン（2026年8月〜）へ移行するため、設定画面にシーズンアーカイブ機能を追加しました。

## 主な変更内容

### シーズンアーカイブ

- **設定 > シーズンアーカイブ** から前シーズンデータを退避
- 退避対象: 特別シーズン期間の試合予定・観戦予定
- **非可逆**（アプリ内からの復元は現時点では不可）
- アーカイブ後はカレンダー・観戦予定一覧・壁紙出力に前シーズンが表示されない
- 2026/2027シーズンのマスタ試合を自動取り込み

### 利用手順

1. 設定画面を開く
2. 「シーズンアーカイブ」で対象件数を確認
3. 「2026特別シーズンをアーカイブ」を実行
4. ページをリロード
