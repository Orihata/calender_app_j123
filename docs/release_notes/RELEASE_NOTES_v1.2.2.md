# リリースノート Version 1.2.2

**リリース日**: 2026-01-XX

## 概要

クラブカラーにヴェルスパ大分（V大分）とジェイリースFC（JLFC）を追加しました。また、色生成ユーティリティを実装し、`original`カラーから全色情報を自動生成できるようになりました。

## 主な変更内容

### クラブカラーの追加

#### ヴェルスパ大分（V大分）
- **original**: `#c7000d`（赤色）
- **全色情報**: 自動生成
  - background1: `#ecc6c8`
  - background2: `#eeddde`
  - text: `#99000a`
  - gradientStart: `#e9d2d4`
  - gradientEnd: `#f0e6e6`

#### ジェイリースFC（JLFC）
- **original**: `#0353a4`（青色）
- **全色情報**: 自動生成
  - background1: `#c6d9ec`
  - background2: `#dde5ee`
  - text: `#004c99`
  - gradientStart: `#d2dee9`
  - gradientEnd: `#e6ebf0`

### 色生成ユーティリティの実装

#### 新規ファイル: `src/utils/colorUtils.js`
- **HEX↔HSL変換機能**: 色空間の変換を実装
- **色の自動生成機能**: `generateTeamColors(originalHex)`関数
  - `original`カラーから全色情報を自動生成
  - HSL色空間を使用した色調整
  - 仕様書に基づいたパラメータで色を生成

#### 色生成ロジック
- **background1**: 明度0.85、彩度50%
- **background2**: 明度0.90、彩度35%
- **text**: 明度0.3-0.4（元の明度に応じて調整）、彩度は維持または微調整
- **gradientStart**: 明度0.87、彩度35%
- **gradientEnd**: 明度0.92、彩度25%

### 技術的改善

- `src/utils/colorUtils.js`: 色生成ユーティリティを追加
  - HEX↔HSL変換関数
  - RGB↔HSL変換関数
  - `generateTeamColors()`関数で全色情報を自動生成
- `public/data/color-master.json`: 
  - 2つのクラブカラーを追加
  - versionを"1.2.2"に更新
  - lastUpdatedを更新

## 使い方

追加されたクラブカラーは、以下の場面で自動的に適用されます：

1. **観戦予定一覧ページ**: ホームチーム・アウェイチームの文字色に適用
2. **カレンダーページ**: 試合カードのホームチーム・アウェイチームの文字色に適用
3. **待受画面画像生成**: カードレイアウト・スティックレイアウトの文字色に適用

## 互換性

- 既存の観戦予定データ: そのまま動作します
- 既存機能への影響: なし
- 後方互換性: 完全に維持されています
- 新規追加クラブ: ヴェルスパ大分（V大分）とジェイリースFC（JLFC）の試合データで、クラブカラーが正しく表示されます

## 注意事項

- 色マスタのキーは略称（"V大分"、"JLFC"）を使用しています
- 試合データのチーム名と色マスタのキーが一致する必要があります
- クラブカラーの追加は開発時にJSONファイルを直接編集する方式です
