# リリースノート - Version 1.1.3

**リリース日**: 2026-01-14

## 🎉 Version 1.1.3 リリース

サッカー試合予定カレンダーアプリケーションのVersion 1.1.3をリリースしました。

## ✨ 新機能・改善

### 手動追加機能の実装

CSVインポート画面に、テキストボックスから手動で試合予定を追加する機能を実装しました。モバイル端末での利用を想定した機能です。

#### 主な機能

- **「手動で追加」ボタン**: CSVインポート画面に追加
- **モーダルフォーム**: 試合予定情報を入力するモーダルフォーム
- **バリデーション**: CSVインポートと同じバリデーション処理を適用
- **エラーハンドリング**: 分かりやすいエラーメッセージを表示
- **モバイル対応**: レスポンシブデザインでモバイル端末でも快適に利用可能

#### 入力項目

**必須項目:**
- **Date**: YYYY-MM-DD形式（例: 2026-02-06）
- **Kickoff**: HH:MM形式または「未定」（例: 19:00）
- **Home**: ホームチーム名
- **Away**: アウェイチーム名

**任意項目:**
- **Group**: グループ名（例: EAST, WEST）
- **Round**: ラウンド番号
- **Stadium**: スタジアム名
- **Broadcast**: 放送局情報
- **Etc**: その他の情報

#### バリデーション

CSVインポートと同じバリデーション処理を適用：

- 必須フィールドのチェック
- 日付形式の検証（YYYY-MM-DD）
- 時間形式の検証（HH:MM または「未定」）
- Dateが「未定」の場合の警告処理
- 空文字列のチェック
- 日時結合の妥当性チェック

#### エッジケース対応

以下のエッジケースに対応：

- Dateが「未定」の場合: 警告を表示し、登録をスキップ
- 必須フィールド未入力: エラーメッセージを表示
- 日付形式不正: エラーメッセージを表示（YYYY-MM-DD形式を要求）
- 時間形式不正: エラーメッセージを表示（HH:MM形式または「未定」を要求）
- 空文字列のHome/Away: エラーメッセージを表示
- 日時結合エラー: エラーメッセージを表示
- 保存エラー: エラーメッセージを表示（重複ID等）

#### UI/UX

- **モーダルデザイン**: 既存のモーダルスタイルに統一
- **必須マーク**: 必須項目に赤色の「*」マークを表示
- **任意マーク**: 任意項目に灰色の「（任意）」を表示
- **成功メッセージ**: 登録成功時に自動でモーダルを閉じる（2秒後）
- **エラーメッセージ**: 入力エラーを分かりやすく表示

## 🚀 使い方

### 手動追加機能

1. CSVインポート画面に移動
2. 「手動で追加」ボタンをクリック
3. モーダルが開いたら、必要な情報を入力
   - 必須項目（Date, Kickoff, Home, Away）は必ず入力
   - 任意項目は必要に応じて入力
4. 「登録」ボタンをクリック
5. バリデーションエラーがある場合はエラーメッセージを確認して修正
6. 登録成功時は自動でモーダルが閉じます

### 注意事項

- Dateが「未定」の場合は登録できません（警告が表示されます）
- 日付は必ずYYYY-MM-DD形式で入力してください（例: 2026-02-06）
- キックオフ時間はHH:MM形式で入力するか、「未定」と入力してください（例: 19:00）
- 手動追加でもCSVインポートと同じバリデーションが適用されます
