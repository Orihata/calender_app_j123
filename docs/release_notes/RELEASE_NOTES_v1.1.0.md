# リリースノート - Version 1.1.0

**リリース日**: 2026-01-09

## 🎉 Version 1.1.0 リリース

サッカー試合予定カレンダーアプリケーションのVersion 1.1.0をリリースしました。

## ✨ 新機能

### 画像出力機能（待受画面用）

- **待受画面画像生成**: 観戦予定一覧から、携帯電話の待受画面用画像を生成
- **カード型レイアウト**: 各試合情報をカード形式で表示
- **最大51試合対応**: 3列×17行のレイアウトで最大51試合を1枚の画像にまとめて表示
- **カスタマイズ可能**: 背景色を選択可能
- **高品質な描画**: Canvas APIを使用した正確な文字割とレイアウト
- **SSOT準拠**: `docs/feature_spec/wallpaper/card_layout_sample.json`をSingle Source of Truthとして実装

#### 機能詳細

- **画像サイズ**: 1080x2400px（縦長、9:20）
- **出力形式**: PNG形式
- **対象**: 現地観戦予定のみ（初回実装）
- **レイアウト**: 
  - カードサイズ: 340px × 135px（横長）
  - 配置: 3列×17行（列優先、縦方向）
  - カード内要素: グループ/ラウンド、日付、曜日、KO時間、会場名、ホームチーム、アウェイチーム
- **デザイン**:
  - 淡い色合いの背景グラデーション（カテゴリ別）
  - 背景色に合わせた濃い文字色
  - Noto Sans JPフォント使用
  - 正確な文字割とレイアウト（card_layout_sample.json準拠）

#### 使い方

1. 観戦予定一覧ページで「画像出力」ボタンをクリック
2. 背景色を選択（カラーピッカー）
3. 「画像を生成」ボタンをクリック
4. プレビューを確認
5. 「ダウンロード」ボタンで画像を保存（ファイル名: `wallpaper_001.png`）

## 🔧 技術的改善

### 実装方式

- **Canvas API直接描画**: HTML+CSSでの描画による表記ずれを回避し、Canvas APIで直接描画
- **SSOT準拠**: `docs/feature_spec/wallpaper/card_layout_sample.json`を唯一の情報源として実装
- **正確なスケーリング**: JSONの座標（659x300px）を実際のカードサイズ（340x135px）に正確にスケーリング

### フォント

- **Noto Sans JP**: BIZ UDGothicからNoto Sans JPに変更
- Google Fontsから読み込み

## 🚀 使い方

### 画像出力機能

1. 観戦予定一覧ページに移動
2. 「画像出力」ボタンをクリック（現地観戦予定がある場合のみ表示）
3. 背景色を選択（カラーピッカー）
4. 「画像を生成」ボタンをクリック
5. プレビューを確認
6. 「ダウンロード」ボタンで画像を保存

### 注意事項

- 現地観戦予定のみが対象です（放送視聴予定は将来対応予定）
- 51試合を超える場合は、最初の51試合のみ表示されます
- 画像生成には数秒かかる場合があります
