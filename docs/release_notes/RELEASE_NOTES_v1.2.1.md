# リリースノート Version 1.2.1

**リリース日**: 2026-01-XX

## 概要

待ち受け画面画像生成機能に「スティックレイアウト」を新規追加しました。既存の「カードレイアウト」に加えて、より簡易的な「スティックレイアウト」を選択できるようになりました。また、UIを整理し、操作性を向上させました。

## 主な変更内容

### スティックレイアウトの追加

待ち受け画面画像生成モーダルに、レイアウトタイプを選択するプルダウンを追加しました。

#### スティックレイアウトの特徴

- **配置**: 1試合ごとに1本のスティックを縦一列に配置
- **最大表示試合数**: 39試合（カードレイアウトと同じ）
- **表示情報**: 日付、曜日、ホームチーム、アウェイチーム、KO時間、会場名、グループ、ラウンド
- **メモエリア**: 高さ2px、メモ内容は非表示（背景のみ表示）
- **下部余白**: 100px
- **カラーリングパターン**: カードレイアウトと同様に3つのパターンに対応

#### レイアウトタイプ選択機能

- **UI**: プルダウンでレイアウトタイプを選択可能
- **デフォルト**: 「カード」（既存動作を維持）
- **オプション**:
  1. **カード**（`card`）: 3列×n行の配置、最大39試合まで表示
  2. **スティック**（`stick`）: 1列×n行の配置、最大39試合まで表示

### UIの改善

#### 背景色選択の改善

- **変更前**: カラーピッカーで任意の色を選択
- **変更後**: ごくごく淡い7色から選択可能（モーダル形式）
  - 選択中の色を1色表示するボタンをクリックすると、色選択モーダルが開く
  - モーダル内に7色をグリッド（4列）で配置
  - モーダル外をクリックすると閉じる
- **選択可能な色**:
  1. 白（`#FFFFFF`）
  2. 淡い青（`#F0F7FC`）
  3. 淡いピンク（`#FFF0F5`）
  4. 淡いグリーン（`#F0FFF0`）
  5. 淡いイエロー（`#FFFFF0`）
  6. 淡いパープル（`#F5F0FF`）
  7. 淡いグレー（`#F5F5F5`）

#### ラベル名称の変更

- **レイアウトタイプ**: 「カードレイアウト」「スティックレイアウト」→「カード」「スティック」
- **カラーリングパターン**: 「カラーリングパターン」→「カラーリング」

#### レイアウトの改善

- レイアウトタイプとカラーリングのプルダウンメニューの左端を揃える
- セレクトボックスの横幅を調整（はみ出しを防止）

### 技術的改善

- `docs/feature_spec/wallpaper/stick_layout_sample.json`: スティックレイアウト定義ファイルを追加（SSOT）
- `src/services/imageExportService.js`:
  - `stickLayoutSpec`を追加
  - `generateWallpaperImage`関数に`layoutType`パラメータを追加（デフォルト: 'card'）
  - スティックレイアウト描画機能を追加（`drawStick`関数、`drawStickMemoArea`関数）
  - スティック配置アルゴリズムを実装（縦一列、最大39個）
- `src/components/common/WallpaperGenerator.jsx`:
  - `layoutType` stateを追加（デフォルト: 'card'）
  - レイアウトタイプ選択UIを追加
  - 背景色選択を7色のモーダル形式に変更
  - ラベル名称を変更
- `src/components/common/WallpaperGenerator.css`:
  - 背景色選択モーダルのスタイルを追加
  - プルダウンのスタイルを調整
- `docs/feature_spec/wallpaper/WALLPAPER_SPEC_v1.2.1.md`: スティックレイアウト仕様書を追加

## 使い方

1. 観戦予定一覧ページで「画像出力」ボタンをクリック
2. **背景色を選択**（7色から選択、モーダル形式）
3. **レイアウトタイプを選択**（プルダウン）
   - カード: 3列×n行の配置
   - スティック: 1列×n行の配置（簡易表示）
4. **カラーリングを選択**（プルダウン）
   - 通常: 応援クラブを強調表示
   - クラシック: ホームクラブを強調表示、メモ欄はデフォルト色
   - ホームゲーム: ホームクラブを強調表示、メモ欄はホームクラブの色
5. 「画像を生成」ボタンをクリック
6. プレビューを確認
7. 「ダウンロード」ボタンで画像を保存

## 互換性

- 既存の観戦予定データ: そのまま動作します
- 既存機能への影響: なし（デフォルトレイアウトタイプが「カード」のため、現行の動作を維持）
- 後方互換性: 完全に維持されています
