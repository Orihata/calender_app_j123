# リリースノート Version 1.2.0

**リリース日**: 2026-01-16

## 概要

待ち受け画面画像生成機能にカラーリングパターン選択機能を追加しました。3つのパターンから選択でき、ユーザーの好みに応じて画像のスタイルをカスタマイズできます。

## 主な変更内容

### カラーリングパターン選択機能の追加

待ち受け画面画像生成モーダルに、カラーリングパターンを選択するプルダウンを追加しました。

#### 実装された3つのパターン

1. **通常パターン**（デフォルト）:
   - 太字: 応援しているクラブ（plan.supportingTeamに基づく）
   - メモ欄の背景色: 応援しているクラブの文字色
   - メモ欄の文字色: 白（#FFFFFF）
   - 説明: 現行の実装と同じ動作。応援クラブが選択されている場合、そのクラブを強調表示します。

2. **クラシックパターン**:
   - 太字: ホームのクラブ（常にhome）
   - メモ欄の背景色: デフォルト色（紺色: #2A456F）
   - メモ欄の文字色: 白（#FFFFFF）
   - 説明: ホームクラブを常に太字で表示し、メモ欄は統一されたデフォルト色を使用します。

3. **ホームゲームパターン**:
   - 太字: ホームのクラブ（常にhome）
   - メモ欄の背景色: ホームのクラブの文字色
   - メモ欄の文字色: 白（#FFFFFF）
   - 説明: ホームクラブを常に太字で表示し、メモ欄の背景色をホームクラブの色に合わせます。

### UIの改善

- **カラーリングパターン選択UI**: 背景色選択の下にプルダウンを追加
  - プルダウンで3つのパターンから選択可能
  - デフォルトは「通常」パターン
  - 選択したパターンに応じて画像生成時のスタイルが変更されます

### 技術的改善

- `src/components/common/WallpaperGenerator.jsx`:
  - `coloringPattern` stateを追加（デフォルト: 'current'）
  - カラーリングパターン選択のプルダウンを追加
  - `generateWallpaperImage`関数に`coloringPattern`パラメータを渡すように変更

- `src/components/common/WallpaperGenerator.css`:
  - プルダウンのスタイルを追加（`.wallpaper-pattern-selector`）

- `src/services/imageExportService.js`:
  - `generateWallpaperImage`関数に`coloringPattern`パラメータを追加（デフォルト: 'current'）
  - `drawCard`関数に`coloringPattern`パラメータを追加し、パターンに応じた太字判定を実装
  - `drawMemoArea`関数に`coloringPattern`パラメータを追加し、パターンに応じたメモ欄背景色を実装

## 使い方

1. 観戦予定一覧ページで「画像出力」ボタンをクリック
2. 背景色を選択（カラーピッカー）
3. **カラーリングパターンを選択**（プルダウン）
   - 通常: 応援クラブを強調表示
   - クラシック: ホームクラブを強調表示、メモ欄はデフォルト色
   - ホームゲーム: ホームクラブを強調表示、メモ欄はホームクラブの色
4. 「画像を生成」ボタンをクリック
5. プレビューを確認
6. 「ダウンロード」ボタンで画像を保存

## 互換性

- 既存の観戦予定データ: そのまま動作します
- 既存機能への影響: なし（デフォルトパターンが「通常」のため、現行の動作を維持）
- 後方互換性: 完全に維持されています
