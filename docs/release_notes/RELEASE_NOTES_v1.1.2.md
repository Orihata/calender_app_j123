# リリースノート - Version 1.1.2

**リリース日**: 2026-01-13

## 🎉 Version 1.1.2 リリース

サッカー試合予定カレンダーアプリケーションのVersion 1.1.2をリリースしました。

## ✨ 新機能・改善

### メモ機能の改善

- **閲覧/編集モード対応**: メモ表示を閲覧モードと編集モードで切り替え可能
  - **閲覧モード**: メモをテキストとして表示（メモがない場合は非表示）
  - **編集モード**: テキストボックスとして編集可能
  - 既存の「閲覧/編集」モードトグルボタンと連動
- **UI改善**: メモがない場合の「（メモなし）」表示を削除

### 画像出力機能の改善

#### フォント変更
- **Noto Serif JP採用**: 画像出力時のフォントをNoto Sans JPからNoto Serif JPに変更
- **iOS対応**: iOSでの代替フォント問題に対応
  - フォント事前読み込み機能を追加
  - タイムアウト付きフォント読み込み処理を実装
  - フォールバックとして`serif`を指定

#### レイアウト調整
- **下端固定**: カード行列の下端を画像下部から350pxの位置に固定
  - 上端はカード数に応じて自動調整
- **最大表示試合数**: 51試合から39試合（13行×3列）に変更
- **カード高さ**: 17行時の高さ（129px）に固定
- **警告表示**: 39試合超過時の警告を画像ではなくモーダルで表示

#### メモエリアのデザイン統一
- **背景色統一**: 現地観戦・放送視聴に関わらず、メモエリアの背景色を統一（紺色: `#2A456F`）
- **文字色統一**: メモテキストの文字色を白（`#FFFFFF`）に統一
- **常時表示**: メモの有無に関わらず、メモエリアの背景を常に表示

## 🔧 技術的改善

### フォント読み込み処理
- `waitForFontsWithTimeout`: タイムアウト付きフォント読み込み関数を追加
- `preloadFont`: iOS向けのフォント事前読み込み機能を実装
- HTMLにNoto Serif JPの読み込みリンクを追加

### 画像生成処理
- カード配置アルゴリズムの改善（下端固定）
- 警告メッセージの表示方法を変更（画像内からモーダルへ）

## 📝 仕様変更

### 画像出力仕様
- **最大表示試合数**: 51試合 → 39試合（13行×3列）
- **カード配置**: 下端固定（画像下部から350px）
- **フォント**: Noto Sans JP → Noto Serif JP
- **メモエリア**: 背景色・文字色を統一

### メモ機能仕様
- **表示モード**: 閲覧モードと編集モードで切り替え
- **表示条件**: メモがない場合は非表示

## 🐛 バグ修正

- メモがない場合の不要な表示を削除
- iOSでのフォント表示問題に対応
