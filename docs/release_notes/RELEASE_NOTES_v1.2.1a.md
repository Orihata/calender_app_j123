# リリースノート - Version 1.2.1a

**リリース日**: 2026-01-XX  
**ブランチ**: 傍系開発（experimental branch）

## 概要

UIデザインシステムをニューモーフィズム（Neumorphism）デザインに全面刷新しました。柔らかく立体的な見た目により、視覚的な深みとモダンな印象を実現しています。

## 主な変更内容

### デザインシステムの刷新

#### ニューモーフィズムデザインの導入
- **浮き出し効果（Outset）**: カードやボタンに浮き上がる影を適用
- **沈み込み効果（Inset）**: コンテナや入力欄にへこむ影を適用
- **背景色の統一**: 全体的に`#f0f0f0`（明るいグレー）の背景色に統一
- **影の調整**: 明るい影と暗い影を組み合わせた立体感のあるデザイン

#### ナビゲーションの改善
- **ヘッダーの軽量化**: ヘッダーの背景色をページ背景と同じ色に変更し、視覚的な重さを軽減
- **フッターナビゲーション**: ハンバーガーメニューを廃止し、画面下部に4つのアイコンを配置
  - 📅 カレンダー
  - ✏️ データ編集
  - 📋 観戦予定
  - ⚙️ 設定
- **選択状態の表示**: アクティブなページは淡い青色の背景と沈み込み効果で表示

#### カードとコンテナの視覚的階層
- **カード（浮き出し）**: 個別のコンテンツカード（試合カード、観戦予定カードなど）は浮き出し効果
- **コンテナ（沈み込み）**: カードをまとめるコンテナは沈み込み効果
- **リスト要素**: 要素をまとめるリストは背景透明で控えめに表示

#### ボタンの色調整
- **青・緑ボタン**: 淡色に変更（`#b3d9ff`、`#b3ffb3`）し、テキスト色を濃いグレーに変更
- **赤ボタン**: 濃い赤（`#dc3545`）を維持し、浮き出し効果に変更（危険操作の明確化）
- **選択中のボタン**: 沈み込み効果とアクセントカラーで明確に表示

#### UIの丸みの強調
- **カード・コンテナ**: `border-radius: 8px` → `20px`
- **ボタン・入力欄**: `border-radius: 4px` → `12px`
- **その他の要素**: 適切な丸みを付与（バッジ: `14px`、カウント: `8px`など）

#### モーダルの改善
- **フッター貫通の修正**: モーダルがフッターナビゲーションを貫通しないよう、高さと位置を調整
- **モバイル対応**: モバイル端末でもフッターを考慮した適切な表示

### 視覚的な改善

#### カレンダー表示
- 観戦予定がある日は黄色（`#fff9c4`）で強調表示
- 選択された日は青色で表示
- カレンダーグリッドは沈み込み効果で表示

#### 試合カード
- 現地観戦予定があるカード: 淡い青色の影で区別
- 放送視聴予定があるカード: 淡い緑色の影で区別
- 背景色は統一し、影の色で区別

#### 観戦予定カード
- カテゴリに応じたアクセントカラー（青・緑）の影で区別
- 背景色は統一し、視覚的な重さを軽減

## 技術的改善

### CSS変更
- 全コンポーネントのCSSファイルを更新
  - `src/App.css`: ヘッダー、フッターナビゲーション
  - `src/components/Calendar/Calendar.css`: カレンダー表示
  - `src/components/Calendar/MatchList.css`: 試合リスト
  - `src/components/AttendanceList/AttendanceList.css`: 観戦予定リスト
  - `src/components/ImportCSV/ImportCSV.css`: データ編集
  - `src/components/Settings/Settings.css`: 設定画面
  - `src/components/common/WallpaperGenerator.css`: 壁紙生成

### デザイン原則
- **浮き出し（Outset）**: カード、ボタン（通常状態）
- **沈み込み（Inset）**: コンテナ、入力欄、選択中のボタン
- **背景色**: `#f0f0f0`（統一）
- **影の強度**: 適度な立体感を保つ範囲で調整
