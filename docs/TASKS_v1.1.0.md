## 技術的検討事項

### IndexedDBへの移行について

- **理由**: localStorageはPWA更新時に失われる可能性がある
- **メリット**: 
  - より大容量のデータを保存可能（数GBまで）
  - 非同期処理でパフォーマンス向上
  - 構造化されたデータの保存
- **実装方針**:
  - 既存のlocalStorageコードとの互換性を保つ
  - IndexedDBをプライマリストレージ、localStorageをフォールバックとして使用
  - 段階的な移行を検討

### 画像出力ライブラリ

- **Canvas API**: ネイティブサポート、追加ライブラリ不要
- **html2canvas**: HTML要素をCanvasに変換（レイアウトが複雑な場合）
- **推奨**: Canvas APIを直接使用（パフォーマンスとファイルサイズの観点）

## 注意事項

- 既存機能への影響を最小限に抑える
- 後方互換性を維持する
- モバイル対応を維持する
- パフォーマンスを監視する
