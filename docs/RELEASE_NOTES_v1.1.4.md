# リリースノート - Version 1.1.4

**リリース日**: 2026-01-15

## 🎉 Version 1.1.4 リリース

サッカー試合予定カレンダーアプリケーションのVersion 1.1.4をリリースしました。

## ✨ 新機能・改善

### 試合予定の削除機能の実装

Version 1.1.3で「将来実装予定」として記載していた試合予定の削除機能を実装しました。

#### 主な機能

- **削除モーダル**: 登録済み試合予定の一覧を表示し、チェックボックスで選択して削除
- **一行表示デザイン**: 一覧性を高めるため、各試合を一行で表示（チェックボックス、日時、ホーム vs アウェイ）
- **詳細情報表示**: 詳細情報（会場、グループ、ラウンド、放送、その他）はiボタンからモーダルで表示
- **全選択/全解除機能**: すべての試合を一括選択または解除
- **削除確認ダイアログ**: 選択した試合情報を表示して削除を確認
- **参照整合性の維持**: 試合予定を削除する際、関連する観戦予定も自動的に削除

#### UI/UX改善

- **モバイル対応**: モバイル端末（768px以下）では削除モーダルを全画面表示し、一行表示スタイルを維持
- **レスポンシブデザイン**: 画面サイズに応じて最適な表示を実現
- **視覚的フィードバック**: 選択中の試合を視覚的に強調表示（青い背景色）

### メニュー構造の再編成

#### メニュー項目の変更

- **「CSVインポート」→「データ編集」**: メニュー項目名を変更し、より包括的な名称に統一

#### データ編集画面の再構成

- **トップページ**: 3つの選択ボタンを表示
  1. 予定の一括登録(CSV)
  2. 予定の手動登録
  3. 予定の削除
- **モーダル構成**: 各機能をモーダルで実装し、トップページからの選択で開く構成に変更

### CSVインポート機能の整理

- **リセット機能の削除**: CSVインポートモーダルから「リセット（全削除）」ボタンを削除
- **機能の統一**: データの全削除は「設定 > データ管理」に統一

## 📚 使い方

### 試合予定の削除

1. メニューから「データ編集」を選択
2. 「予定の削除」ボタンをクリック
3. 削除モーダルで試合予定の一覧を確認
4. 削除したい試合にチェックを入れる（複数選択可能）
5. 「選択した試合を削除」ボタンをクリック
6. 確認ダイアログで削除を確定

### 詳細情報の確認

- 試合にiボタンが表示されている場合、クリックすると詳細情報（会場、グループ、ラウンド、放送、その他）をモーダルで表示

### データ編集画面

1. メニューから「データ編集」を選択
2. トップページで以下のいずれかを選択：
   - **予定の一括登録(CSV)**: CSVファイルから一括登録
   - **予定の手動登録**: フォームから個別登録
   - **予定の削除**: 登録済み試合予定の削除
