# リリースノート Version 1.1.5

**リリース日**: 2026-01-16

## 概要

観戦予定に「応援クラブ」機能を追加し、編集モードでhome/awayを選択できるようになりました。また、クラブカラーの読み込みタイミングを改善し、UIの操作性を向上させました。

## 主な変更内容

### 応援クラブ機能の追加

- **応援クラブ選択機能**: 観戦予定一覧ページの編集モードで、home/awayのどちらを応援するかを選択可能に
  - 選択値: `home` / `away` / `null`（中立）
  - 排他選択: homeとawayは排他的に選択（一方を選択すると他方は解除）
  - トグル機能: 選択中のクラブを再選択すると選択解除（中立）になる
  - ボタンスタイル: 編集モード時にhome/awayのクラブ名をボタンとして表示
  - 選択時のスタイル: 文字色と背景色（文字部分のみ）を反転表示
- **データモデル**: `AttendancePlan`モデルに`supportingTeam`フィールドを追加
- **データ保存**: 応援クラブの選択状態をlocalStorageに保存

### クラブカラー読み込みの改善

- **即座に反映**: 画面表示直後からクラブカラーが正しく表示されるように改善
  - 色マスタの読み込み完了をstateで管理
  - 読み込み完了後に再レンダリングをトリガー
  - 以前は何らかのアクション後に色が反映されていた問題を解消

### UIの改善

- **固定表示エリア**: 見出し「観戦予定一覧」とボタンエリア（現地観戦/放送観戦/画像出力/閲覧/編集）を一緒に固定表示
  - スクロール位置に関係なく、常にボタンにアクセス可能
  - ヘッダーの下に固定表示（`position: sticky`を使用）
  - ヘッダーとの隙間を完全に解消
- **スタイル統一**: 閲覧モードと編集モードでhome/awayのスタイルを統一
  - 閲覧モードでもボタン形式で表示（選択不可）
  - 選択状態（応援クラブ）が閲覧モードでも視覚的に表示される
- **スクロール位置の保持**: 編集モードで応援クラブを選択した際、ページが最上部にスクロールしないように改善

### 技術的改善

- `src/models/AttendancePlan.js`: `supportingTeam`フィールドを追加
- `src/services/attendanceService.js`: `updateAttendancePlan()`で`supportingTeam`を更新可能に
- `src/components/AttendanceList/AttendanceList.jsx`: 
  - 応援クラブ選択機能の実装
  - 色マスタ読み込み完了のstate管理
  - 固定表示エリアの実装
- `src/components/AttendanceList/AttendanceList.css`: 
  - ボタンスタイルと選択時の反転スタイルを追加
  - 固定表示エリアのスタイル実装

## 将来実装予定

- 画像出力時の応援クラブ反映: 応援クラブに基づいて、いずれかのチーム名のfont-weightを高くする機能（仕様未定のため今回未実装）

## 互換性

- 既存の観戦予定データ: `supportingTeam`が`null`（中立）として扱われます
- 既存機能への影響: なし
